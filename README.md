## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/adeel-151/xarkode.git
   cd xarkode
   ```

2. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Backend Setup** (Optional/Future implementation)
   ```bash
   cd backend
   npm install
   npm run dev
   ```
